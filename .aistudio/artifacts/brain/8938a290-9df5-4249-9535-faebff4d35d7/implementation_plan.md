# توثيق رواية حفص عن عاصم وتهيئة النشر السحابي الساكن على Cloudflare Pages

تهدف هذه الخطة إلى التوثيق والإشهار الواضح لرواية التلاوة وأحكام التجويد الملونة بأنها **برواية حفص عن عاصم بن أبي النَّجود من طريق الشاطبية** وفق الرسم العثماني المعتمد لمجمع الملك فهد لطباعة المصحف الشريف، بالإضافة إلى تهيئة المشروع للبناء والنشر السلس بنقرة واحدة على **Cloudflare Pages** ومستودعات GitHub بدون أية أخطاء خادم أو إخفاقات بناء.

---

### مراجعة المستخدم والقرارات المؤكدة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم تأكيد الخيارات التالية بناءً على إجاباتك الكريمة في المرحلة التوضيحية:
> - **المنصة المستهدفة للنشر**: `Cloudflare Pages` بشكل أساسي، مع دعم معايير الاستضافة الساكنة الحديثة (Vite SPA Static Hosting).
> - **طريقة معالجة التدبر والبحث**: نظام تدبر وبحث محلي فوري أصيل ومدمج 100% لا يعتمد على خادم Node.js خلفي، لمنع أي خطأ اتصال `Failed to fetch from server` عند استضافة الموقع مجاناً على Cloudflare Pages.
> - **توضيح الرواية للمستخدمين**: إبراز **رواية حفص عن عاصم من طريق الشاطبية** في شريط الترويسة، ودليل التجويد التفصيلي، ومحاكي مصحف المدينة، وشريط مفاتيح التجويد الملونة.

---

## 1. نظرة عامة وتجربة المستخدم (Overview & Core Concept)

- **الرواية المعتمدة**: إشهار واضح ودقيق بأن النص القرآني وأحكام التجويد الملونة (المدود، الغنة، الإدغام، الإقلاب، الإخفاء، القلقلة) مبنية حصراً على **رواية حفص عن عاصم الكوفي من طريق الشاطبية (حرز الأماني ووجه التهاني)** ومطابقة لمصحف المدينة النبوية الصادر عن **مجمع الملك فهد لطباعة المصحف الشريف**.
- **الجاهزية للنشر على Cloudflare Pages**:
  - ضبط أوامر البناء ومجلد المخرجات القياسي `dist/`.
  - إضافة ملف التوجيه المكتمل `public/_redirects` لضمان عمل نظام المسارات والصفحات والتحديث (SPA Routing) في Cloudflare Pages بنجاح 100%.
  - إضافة ملف التوافقية `.nvmrc` لضمان اختيار بيئة Node.js 20+ تلقائياً في سحابة Cloudflare.
  - تحويل وظيفة التدبر القرآني في `TafsirTadabburModal` إلى محرك تأملي ولغوي إيماني محلي وسريع وموثوق يعتمد على نصوص التفاسير المعتمدة دون الحاجة لطلب خادم خلفي.
  - توفير ملف إرشادات النشر `DEPLOYMENT.md` و `README.md` لإرشاد المستخدم خطوة بخطوة عند ربط مستودع GitHub بـ Cloudflare Pages.

## 2. الهوية البصرية وتجربة الواجهة (User Experience & Visual Identity)

- **توثيق الرواية في الواجهة**:
  - **الشريط العلوي (Navbar)**: إضافة شارة نصية هادئة وفخمة تحت اسم المصحف: `رواية حفص عن عاصم · طريق الشاطبية`.
  - **دليل التجويد (TajweedGuideModal)**: قسم تمهيدي خاص بعنوان «توثيق الرواية والسند»، يشرح أن هذه الأحكام والألوان هي لرواية الإمام حفص بن سليمان بن المغيرة الأسدي الكوفي عن الإمام عاصم بن بهدلة أبي النَّجود، برسم مجمع الملك فهد بالمدينة المنورة.
  - **مفتاح الألوان (Tajweed Legend)**: عبارة توضيحية أعلى المفتاح تفيد بضبط المدود والإدغامات وفق طريق الشاطبية.
  - **محاكي صفحات المصحف (MushafPageView)**: ترويسة صفحة المصحف النبوي الشريف (604 صفحات) مع إشارة صريحة إلى ضبط المدينة المنورة.
- **التصميم المتناسق**: الحفاظ على جمالية الخط الكوفي والنسخي العربي الأصيل (Amiri Quran / Scheherazade New) وتطبيق معايير الخط والتباين للوضعين الفاتح والداكن (الوضع الليلي الزمردي والذهبي).

### التغييرات البرمجية المحددة:
1. **تحديث `vite.config.ts`**:
   - إزالة التحذيرات المتعلقة بـ `__dirname` واستبدالها بـ `import.meta.dirname` أو المسارات القياسية.
   - التأكد من ضبط `base: './'` أو `'/'` للتوافق التام مع النطاقات المخصصة والنطاقات الفرعية المجانية على `pages.dev`.
2. **إضافة ملفات بيئة Cloudflare Pages**:
   - `public/_redirects`: محتواه `/* /index.html 200` لضمان عمل SPA routing.
   - `.nvmrc`: لتثبيت إصدار Node 20.
3. **تطوير التدبر القرآني المحلي (`TafsirTadabburModal.tsx`)**:
   - معالجة التدبر بالكامل في جانب العميل استناداً إلى الآية والتفسير المعتمد المختار، وتجنب أي خطأ `Failed to fetch from server`.
4. **تحديث نصوص الرواية في المكونات**:
   - `src/components/Navbar.tsx`
   - `src/components/TajweedGuideModal.tsx`
   - `src/components/MushafPageView.tsx`
   - `src/components/SurahContinuousView.tsx`
   - `index.html` (وسوم الميتا والعنوان)
5. **ملف الإرشادات الشامل (`DEPLOYMENT.md`)**:
   - شرح إعدادات لوحة تحكم Cloudflare Pages:
     - Framework preset: `Vite`
     - Build command: `npm run build`
     - Build output directory: `dist`
     - Root directory: `/`

## 4. خطة التحقق والاختبار (Verification Plan)

- **فحص البناء المكتبي والنوعي**: تشغيل `npm run build` و `npm run lint` للتأكد من خلو المشروع تماماً من أي خطأ بناء أو تحذيرات تمنع اكتمال البناء في Cloudflare.
- **التحقق البصري بالمتصفح**:
  - التأكد من وضوح عبارة "برواية حفص عن عاصم من طريق الشاطبية" في الترويسة ومودال التجويد ومحاكي المصحف.
  - فتح نافذة التدبر القرآني والتأكد من ظهور التأملات والدرر اللغوية والفوائد السلوكية فورياً دون أي خطأ شبكة.
  - فحص ملفات النشر والتوجيه في مجلد `dist/`.
